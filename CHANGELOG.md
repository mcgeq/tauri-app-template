# Changelog

## [0.0.1] - 2026-06-07

### Added

- Tauri v2 + React 19 + TypeScript + Vite 8 project scaffold
- shadcn/ui component library with Tailwind CSS v3
- next-themes based theme system (light/dark/system) with daisyui-inspired cupcake/forest palettes
- i18next internationalization (English & Chinese)
- Custom frameless title bar with window control buttons
- Multi-window management (main, settings, about)
- System tray integration with localized menu
- Global shortcut registration with settings UI
- Command palette (Ctrl+K) for quick navigation and actions
- Zustand state management with persist (window behavior)
- TanStack Router for client-side routing
- TanStack Query for server state management
- Tauri API layer with typed command wrappers
- Toast notifications via sonner (portal to #toaster-root)
- Auto-update support with GitHub Actions release workflow
- ESLint (antfu/eslint-config) with import sorting and formatting
- Vitest + Testing Library test setup
- Bundle analysis with rollup-plugin-visualizer
- Release version management script (release-version.mjs)
- Command palette (cmdk) with theme/language/window commands
- Zod form validation with i18n error messages
